# Personal Portfolio Website — HTML & CSS Internship Project

**Author:** Gude Rajesh  
**Technologies:** HTML5 and CSS3 only (no JavaScript, frameworks, backend or database)

## Project description (for the submission form)
This is a responsive personal portfolio website built with semantic HTML5 and a single external CSS file. It has a sticky navigation bar, a hero section, an About section, six skill cards, two project cards with the technologies used, a contact section with email, LinkedIn and GitHub links, and a footer with a copyright line. Each project card also links to my GitHub profile. The layout uses CSS Grid and Flexbox, CSS variables for the colour palette, hover and focus states on links, buttons and cards, and media queries so the page works on mobile, tablet and desktop without horizontal scrolling. I also added a skip-to-content link, descriptive link text and accessible colour contrast.

## How to view
Open `index.html` in any modern browser. No internet connection is needed: the two fonts (Manrope and DM Mono, both open-source) are bundled in the `fonts/` folder.
